# 资产与交付运行说明

使用原有本地中间件，启动API与worker两个独立进程。上传前通过管理员存储配置接口建立S3_COMPATIBLE配置，endpoint/region与部署环境一致、credentialRef为local-minio、access为PRIVATE。将该记录ID设置为环境变量ZX_UPLOAD_STORAGE_ID。密钥继续由受保护环境文件提供，不写进请求、数据库明文或文档。

扫描配置：ZX_CLAMAV_HOST为内部可信ClamAV地址，ZX_CLAMAV_PORT默认3310。必须独立部署扫描器并更新病毒库；本次未部署真实扫描服务。不要把测试Mock用作生产扫描。扫描未就绪时允许排队，但不会READY或下载。worker轮询ZX_ASSET_POLL_MS默认1000毫秒；失败退避最多一小时，8次后任务FAILED，后续需要受控重试能力。

顺序：创建上传会话→严格带返回headers向MinIO PUT文件→调用complete→查询资产→worker验真和扫描→READY→创建交付新版本→发布→本人学生查询和签名下载。普通资产响应不含对象键和下载地址，授权响应不可记录到日志。

收款使用RECEIPT归属的READY资产，核验接口要求Idempotency-Key与If-Match；重复同键不重复入账。项目文件使用PROJECT归属资产，交付发布/撤回同样要求幂等键和并发版本。下载是只读签名请求，不要求幂等键。

已完成项目仍可撤回有问题的交付版本；已签名链接可能继续有效至一分钟到期。需要即时撤销时应另加受控下载代理，不能声称S3预签名本身即时失效。

未完成：对象GC与孤儿清理、扫描任务人工恢复接口、病毒库运行验证、转码、知识索引、OSS生产适配。正式应用数据库没有测试账户或默认可用上传配置。隔离测试中真实访问MinIO，但扫描使用测试替身；扫描协议由独立TCP测试对端验证。

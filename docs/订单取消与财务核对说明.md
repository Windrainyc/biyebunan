# 订单取消与访问撤销

CANCEL允许DRAFT、CONFIRMED、ACTIVE。先锁订单；模型运行创建也必须取得同一订单锁，因此取消检查后无法再插入新的预占。存在RESERVED/RUNNING运行或RESERVED/RECONCILING额度预占时返回422 ORDER_CANCEL_UNSETTLED，必须先取消运行、等待结束或完成可信用量核对。

通过检查后，同一数据库事务暂停非DONE/PAUSED项目并记录阶段历史、失效PENDING/READY绑定挑战、追加不可变order_cancellation快照、变更订单状态、写审计和outbox。原交付版本、收款凭证及模型账本保留。已完成项目仍保留DONE事实。

学生项目列表、详情、资料、聊天和订单关联知识权限按订单状态过滤。中介仍能查看名下订单的取消记录和项目进度，不能读取私聊。原先已签发的短期对象下载地址在有效期内仍可能可用，这是签名URL的撤权延迟边界。

响应cancellationFinancialReviewRequired在已取消且已确认收款时为true。此字段表示需要财务核对，不是退款成功；系统没有外部退款网关，不自动改写receiptStatus或伪造资金流水。退款须按实际收款渠道核实和执行，后续接支付渠道时另行设计退款凭证及对账闭环。

验证：72项测试通过，覆盖未结束运行/未知冻结拒绝且事务不留快照、ACTIVE取消、重复幂等请求、项目暂停、学生撤权及快照不可变。V54为新增迁移；接口契约1.0.23，路由数仍243。

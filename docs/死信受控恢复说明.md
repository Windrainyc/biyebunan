# 单条统计死信恢复

仅显式执行 `python3 scripts/run-local.py replay-dead`，不在正常API或worker启动时自动恢复。通过受保护环境传入ZX_REPLAY_EVENT_ID、ZX_REPLAY_ACCESS_TOKEN、ZX_REPLAY_REASON；不要把令牌放在命令行参数、Git或报告。令牌必须属于有效管理员会话并具有post_admin_jobs_id_retry权限，不能仅声明管理员ID。

工具固定操作zx.activity.dead，一次最多检查100条，定位指定messageId。原始消息字节交原ActivityInbox核对本地outbox、摘要去重和统计投影，恢复审计与消费同事务提交，然后才ACK目标。其余消息及失败目标逐条NACK重入原队列；连接中断由broker重入未确认消息。提交后ACK失败可再次恢复，inbox确保不会重复累计。未找到目标报错，不清空队列；不提供跳过校验或丢弃消息选项。

此工具仅恢复统计订阅死信，不能用于重新派发已开始的模型调用、付款、扫描等任务。消息内容错误仍失败，必须修复产生错误的原因。真实隔离RabbitMQ队列与PostgreSQL测试验证权限拒绝保留消息、指定恢复、重复去重、非目标保留及审计。69项测试全部通过。

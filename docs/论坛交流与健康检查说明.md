# 论坛交流与健康检查

## 本阶段能力

V39帖子及标签关系、V40评论和举报。学生发帖/编辑/软删除/查看、主评论和一层回复、本人评论软删除、举报；管理员目录、审核/隐藏/锁定/解锁/置顶、评论隐藏恢复、举报结论。所有写入使用幂等键，已有资源更新使用If-Match；成功变更与审计/outbox同事务。

学生只可见启用板块内PUBLISHED/LOCKED及本人PENDING。HIDDEN对作者也不可读。编辑仅本人PENDING/PUBLISHED，重新应用目标板块审核策略并撤销置顶。锁帖禁止编辑、删除帖子和新增评论；作者仍可撤回自己的评论。板块停用即时阻断学生读取。删除帖子保留记录和外键，管理员普通目录也不返回软删除内容。

APPROVE仅处理PENDING/HIDDEN；LOCK仅PUBLISHED；UNLOCK仅LOCKED；PIN仅PUBLISHED/LOCKED；HIDE清除置顶。评论治理只接受APPROVE/HIDE，其他动作422；隐藏/删除父评论后，学生列表过滤其回复，恢复父评论会重新显示仍已发布的回复。回复深度明确为一层，跨帖和过深parentId返回422。

每人每帖一条举报。重复原因返回既有记录，换原因409，已处理不重复建单。处理RESOLVED/DISMISSED不隐式改变帖子状态，管理员必须通过帖子审核接口治理内容，两个动作分别审计。发帖每分钟5条，评论和举报各20条；依靠服务端账户锁串行化计数，软删除不重置频次。频次是初始可调产品策略，不是性能容量承诺。

## 并发与引用

幂等入口持账户锁；标签关联写持category_tree_mutex后，按ID顺序持板块锁，再锁帖子。其他评论/审核持板块→帖子，举报结论仅锁举报。移动板块时二次复核原归属，发现并发变更返回412。两个不同管理员同版本审核只有一方成功，另一方412。

板块与标签的真实外键RESTRICT已验证。软删除帖子继续保护历史引用；不进行物理删除或级联清除讨论。帖子标签列表每页最多100条，当前逐帖读取标签，后续性能阶段可批量优化。

## 明确边界

论坛资产归属尚未接入，assetIds非空返回503 FORUM_ASSETS_UNAVAILABLE，绝不忽略附件。用户可先创建正文，后续补齐安全上传/发布版本链路。原始正文按Markdown/纯文本保存，Vue前端必须禁用原始HTML并净化链接；本阶段没有完成浏览器XSS渲染验证。论坛索引、帖子通知、敏感内容自动检测也未启用，隐藏内容不会由当前未接通渠道外发。

## 健康契约

/api/v1/health/live和/ready无需登录，只有UP/DOWN且no-store。复用Actuator的liveness和readiness组，不返回细节；readiness包含readinessState、PostgreSQL、Redis、RabbitMQ。非UP、组缺失或检查异常返回503 DOWN；数据库不可用不意味着进程失活。503健康响应契约修订为Health而非通用ProblemDetail。未验证真实多节点故障演练。

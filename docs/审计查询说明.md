# 管理员审计查询

GET /api/v1/admin/audits 使用 get_admin_audits 权限，响应禁止缓存。分页1起、每页最多100，q按动作、资源类型和资源ID字面搜索，转义通配符；创建时间升降序附加ID保证稳定顺序。列表与计数在同一只读重复读快照中执行。

审计为追加记录，不提供修改、删除、启停或更新时间排序。传入status或updatedAt排序明确400。V42建立创建时间及资源追溯索引；当前包含式搜索不承诺大规模毫秒级响应，应按真实负载评估索引和归档。

只返回标识、操作者、动作、资源类型/ID、业务理由及创建时间，不返回detail原始JSON。没有chat:audit权限时过滤conversation、conversation_catalog、generation_run、chat_message资源，连总数也不泄露这些记录。中介不能访问此管理端。

历史记录未保存请求追踪编号，traceId诚实返回null，理由不存在同样为null；OpenAPI 1.0.16修订此空值语义并补resourceType。后续统一链路追踪需接入真实请求上下文，不能用本次读取时间或随机ID伪装历史关联。

集成测试验证权限前后总数、分页、非法筛选、私聊元数据隔离和detail不外泄；静态DTO检查不替代这些HTTP验证。

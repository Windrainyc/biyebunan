# 论坛板块与站内通知

本阶段实现论坛板块配置、学生启用板块字典、通知模板目录、三端本人收件箱及交付发布通知。帖子、评论、举报和审核仍未实现，不可据板块接口宣称论坛完成。

## 配置与接口

管理员 `/api/v1/admin/forum-boards`、`/api/v1/admin/notification-templates` 支持分页、名称代码字面搜索、启停过滤、白名单时间排序、详情、增改删、启停。所有关键写使用 Idempotency-Key，更新与删除要求 If-Match；唯一代码由数据库保证，状态修改和审计/outbox同事务。未引用配置允许硬删除，后续帖子或模板引用必须使用 RESTRICT 外键并协同锁记录，禁止级联删除。当前尚未有帖子表或模板消费关联，不把未来引用保护宣称已验证。

板块 requiresReview 为后续新帖审核策略，改变该值不会自动审核现有内容；sortOrder为非负配置。学生 `/api/v1/student/dictionaries/forum-boards` 只返回启用项，DISABLED筛选返回空。中介不能访问学生入口。

通知模板 channel 支持 SMS/IN_APP。providerTemplateId 对应供应商模板号或受控站内渲染器代码；配置启用不代表供应商连通。当前交付通知采用代码内固定安全短文案，尚未消费模板目录，不执行模板表达式，不发送短信。

## 私有收件箱与一致性

三端 `/api/v1/{platform}/notifications` 只查询本人；即使管理员有通知权限也不能读其他人的收件箱。status支持READ/UNREAD，排序为createdAt:asc/desc、updatedAt:desc；无效状态或排序400。`POST /{id}/read`单向变更天然幂等，重复读不会再次改变时间或追加审计；不存在及非本人均404。该操作没有可丢失的覆盖写，因此使用幂等键，不增加CAS版本。

交付版本发布、审计、领域outbox事件、通知投递任务同事务提交。任务只保留接收者标识及通用短文案，不含题目、私聊原文、附件地址或访问令牌。资料被撤回后通知仍是通用提示；实际资料接口始终重新校验当前权限。

独立worker每5秒最多处理50条通知任务。短事务SELECT FOR UPDATE SKIP LOCKED领取，收件箱唯一约束(recipient_id,event_id)去重，插入与DELIVERED标记同事务。崩溃回滚后重做，不需要跨外部调用租约。接收者不存在标为FAILED/RECIPIENT_MISSING；技术故障回滚并下轮重试。暂未增加该任务的管理端重试入口和保留期GC。

任务表收件人快照刻意没有账户外键：发布事务已持订单/项目锁，若再获取学生外键锁，会与学生账户→项目的锁序反转。worker不持项目锁，最终收件箱有真实账户外键，避免在业务发布事务中引入反向等待。内部deliver/enqueue必须运行在已有事务中，没有外部任意发送接口。

## 契约与验收

OpenAPI 1.0.13-development明确通知状态筛选与本人数据范围。V35板块、V36模板、V37收件箱、V38投递任务独立迁移。23种响应DTO静态字段检查覆盖本次新增响应；静态字段匹配不代表所有运行值或状态分支验证。

集成测试覆盖配置幂等/唯一/CAS/停用与跨端拒绝、通知同事件并发去重/冲突载荷/事务回滚、两个worker竞争、三端收件人隔离、重复已读仅一次审计、真实交付发布后的投递。测试使用隔离schema，未调用真实短信或付费模型。

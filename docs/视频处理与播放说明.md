# 视频处理与私有播放

原始文件通过既有扫描后才能进入视频任务。独立worker以固定FFmpeg程序处理，API镜像不包含转码工具。任务使用数据库租约和代次，外部读取、探测、转码和上传均不占用数据库长事务；旧执行器不能覆盖新结果。

输入上限500 MiB、30分钟、8192边长及16777216像素；仅允许指定本地容器格式，禁用网络协议。输出H.264/AAC MP4、最大宽1280、上限1 GiB，执行限时10分钟。源文件及交付版本不覆盖。失败任务在管理任务列表中显示，管理员通过既有恢复接口、原因和If-Match进行恢复。

管理员和学生下载接口增加可选variant=PLAYBACK；默认ORIGINAL。播放沿用原始资产业务授权、扫描状态和存储启停校验，未就绪明确返回VIDEO_NOT_READY，不返回公开桶地址。生成物在上传前登记GC，成功产物受当前任务引用保护，旧代次产物延迟清理。

知识库视频索引目前仅包含标题元数据；不包含语音转写、画面OCR或视频语义理解。

## 运行与验证

使用Dockerfile.worker构建独立worker镜像。FFmpeg锁定Ubuntu包7:4.4.2-0ubuntu0.22.04.1；宿主测试版本8.1.1。配置ZX_VIDEO_ENABLED、ZX_FFMPEG_PATH、ZX_FFPROBE_PATH；默认应用不启用，专用worker镜像显式启用。需为/tmp和进程配置足够内存，当前单任务执行，扩容前实测资源。

72项自动测试通过，覆盖真实合成视频转码、非法字节拒绝、临时目录清理、真实PostgreSQL/MinIO写入、播放权限、GC引用保护、视频标题索引和失败任务CAS恢复。独立worker镜像内亦验证合成视频转码。不是任意编码兼容性、生产吞吐或跨节点高可用证明。

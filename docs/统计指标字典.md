# 三端统计指标字典

所有日期使用Asia/Shanghai，from/to均包含、最大366天，禁止未来日期和2000年前日期。查询同一主库只读重复读快照，generatedAt是数据库事务开始时间，lagSeconds=0表示未使用异步投影，不代表不存在提交或网络延迟。有数据日期才返回指标；无记录返回空列表，不伪造演示值。

| metric | 时间与口径 | 单位 |
|---|---|---|
| orders_created | 按订单创建时间计数，包含取消/归档历史 | count |
| orders_face_amount | 同批创建订单的票面金额总和，不代表收款 | CNY |
| receipts_confirmed_amount | 人工收款确认时间的金额，非凭证填写的到账时间 | CNY |
| projects_created | 按项目创建时间计数 | count |
| delivery_publications | 按交付PUBLISHED事件时间计数；每次版本发布算一次，之后撤回不抹除历史 | count |
| model_settled_amount | 追加账本SETTLE入账时间的原结算金额 | CNY |
| model_adjustment_amount | ADJUSTMENT入账时间的有符号金额，退还为负，与原金额分列 | CNY |
| model_correction_amount | CORRECTION入账时间的有符号金额差额，不改写原结算日期 | CNY |
| model_correction_tokens | CORRECTION入账时间的有符号词元差额；可能为负 | token |
| model_settled_tokens | SETTLE入账时间的输入加输出词元，缓存词元已含在输入内不重复加 | token |
| model_unresolved_runs | 查询时仍处于RECONCILING的运行，按预占创建日分桶，属于当前未决存量而非历史日终快照 | count |
| active_students | 当日创建论坛帖子/评论或模型运行的学生，按审计操作者去重；不把worker或一般管理员操作计入 | count |

学生只能查本人数据；中介仅前五个业务指标，范围来自查询时订单partner_id，归属转移后立即变更历史查询范围，不含学生私聊、模型或活动指标。管理员必须具备管理端统计权限才能查看聚合，账务指标另外要求billing:read，否则不返回这些指标；不返回消息文本、用户明细和密钥。

金额以数据库十进制字符串返回，不用浮点数。未知用量不当零成本计入已结算指标。V43增加时间范围索引；未对真实生产规模做性能承诺。

验证覆盖北京时间零点、当前中介归属变化、学生/管理端隔离、重复活动去重、票面金额与收款区分、已结算金额/词元/调整/未知数量及其他学生不可见。全局event_activity_day不用于这些范围统计。

首页近7日净入账词元为同一区间原结算加更正差额，允许负数；不是按原调用日期重算历史使用量。

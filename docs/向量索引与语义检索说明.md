# 向量索引与语义检索

现有GET /api/v1/student/knowledge-search默认mode=KEYWORD；显式mode=SEMANTIC使用嵌入与pgvector。未部署或未开启嵌入服务返回503，不静默返回假语义结果。契约版本1.0.21。

## 部署与模型空间

ZX_EMBEDDING_ENABLED默认false；ENDPOINT为完整嵌入HTTP地址，MODEL为固定模型标识，DIMENSIONS默认1536、允许1至2000，API_KEY从受保护环境加载。模型版本应使用不可变标识；供应商更换同名模型时应调整MODEL标识或端点并重建。端点/模型/维数的SHA-256指纹隔离向量空间，旧空间不会用于新查询。嵌入端点遵循OpenAI兼容的input/model及data[].embedding响应结构，不承诺所有供应商均兼容。已验证本地确定性HTTP服务协议，未产生付费调用，不代表已部署生产语义模型。

## 索引与未知结果

关键词索引产生当前发布快照的分片；独立嵌入worker每轮加入最多100个新分片，领取一个任务。只有当前发布、READY、代次与版本匹配的任务可领取。外部请求不持有数据库事务，HTTP不自动重试、不跟随重定向，30秒超时、响应上限1MiB，验证维数、有限数字与非零向量。

租约代次保证旧结果不能覆盖；超时RUNNING标为EMBEDDING_OUTCOME_UNKNOWN，不再次自动派发可能收费的请求。明确失败也不无限重试。管理员按已有重建索引动作生成新分片可重新发起，此操作可能产生新的供应商费用，需先查明失败原因。删除旧分片级联清理对应向量/任务，内容正文快照仍不可变。

embedding_request_audit记录INDEX/SEARCH、配置指纹、可空输入词元及安全错误码，不保存文本和密钥；供应商未知用量为空。该用量属于检索基础设施，未自动扣学生问答额度，也没有凭空推算价格。供应商账单对账和部署预算仍需配置。

## 查询语义与性能边界

使用精确余弦相似度，最低0.2，查询内同时过滤学生当前权限、内容发布状态、版本和代次，每内容选最高分片段。分页仍遵循原sort时间排序，score供展示，不能把该接口称为全局按相关度排序。类别、标签、类型过滤与关键词模式相同。查询向量在事务外获取，结果与计数在只读同快照事务执行。撤回和撤权后不会从残留向量中返回内容。

当前未启用HNSW近似索引，避免尚未验证的过滤召回损失；数据增大后需压测再决定ANN索引和参数。参考[pgvector官方查询与过滤说明](https://github.com/pgvector/pgvector)。本地已有public.vector 0.8.7，迁移V51要求运维先安装扩展，应用账号不拥有安装扩展权限。

## 验证

70项测试通过；真实PostgreSQL/pgvector写入与相似度查询、本地HTTP嵌入协议、真实用量、会员过滤、索引代次变更、撤回不可查询、错误维数拒绝。没有生产模型质量评测、语义召回率基准或容量承诺。

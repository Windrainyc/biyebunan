# 本机隔离模型与浏览器验证

仅用于现有 `zx_ui_` 验证库；固定文本和固定8输入/12输出词元是协议夹具，不代表真实模型质量或计量。生产网关仍默认关闭，不请求外部供应商、不产生费用。

先启动 `python3 scripts/start-ui-model.py`（HTTPS localhost:18444），再使用 `python3 scripts/start-ui-verification.py --test-sms --test-model --resume` 与 `python3 scripts/start-ui-worker.py --test-model`。仅显式参数打开本机模型；allowed hosts限制localhost，使用受保护目录中测试证书的专用truststore，未关闭TLS验证。worker仍使用隔离数据库及专用RabbitMQ vhost。

`prepare-ui-model.py`通过正式管理员接口配置测试模型、未来生效价格、只写加密密钥、会员方案及授权。夹具已存在时拒绝重复创建；部分失败应检查已完成步骤再恢复。凭据和调用记录仅存secrets，调用日志仅runId/时间、不存消息或密钥。

断线验证可设置 `ZX_UI_MODEL_DELAY_SECONDS=5` 启动协议服务（允许0至5秒）。2026-10-28实测：知识资料发布v1后可检索、撤回立即无结果、重新发布产生v2且保留已撤回v1；学生引用v2创建问答，答案和引用保存。第二次问答运行中刷新，恢复同一运行，最终历史保存两个问答；协议服务仅两次请求、两个不同runId，用量页面恰好两条已结算记录，每条8/12词元、0.000020金额，无刷新重派。该金额仅隔离测试价格计算，不是付费交易。

浏览器证据在前端reports/knowledge-*.png、chat-reference-history.png、chat-resumed-history.png、chat-usage-settled.png。当前验证API/worker运行源码JAR；最新容器尚需重建验收。

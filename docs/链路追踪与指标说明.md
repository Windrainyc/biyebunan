# 链路追踪与指标

采用Spring Boot 4.0.8管理的OpenTelemetry与Micrometer依赖，版本由父BOM锁定。HTTP自动生成Span；模型运行和事务outbox保存W3C traceparent，worker恢复父链路，消息投递/消费继续关联。目标UUID仅作为Span属性，不作为高基数指标标签；baggage不随持久任务保存。

采样配置ZX_TRACE_SAMPLE_RATE默认0.1。ZX_OTLP_ENABLED默认false，显式开启后通过ZX_OTLP_ENDPOINT发送到部署方受控Collector。未配置Collector时不向外部服务发送遥测。指标采用Prometheus抓取，OTLP指标导出关闭。

/actuator/prometheus要求有效会话和get_admin_statistics权限，匿名401，无权限403。生产应使用专用最小权限观测账户，限制网络入口，并妥善处理会话轮换，不公开指标。

HTTP高基数属性全部移除，只保留框架提供的方法、路由模板、状态等低基数标签；不导出完整URL和查询参数。手工Span仅记录固定错误码，不记录异常正文或堆栈。日志同时保留服务端requestId及traceId/spanId；业务审计中的traceId历史字段仍表示服务端请求UUID，两者不能混淆。

74项测试通过：上下文恢复/父子关系/线程清理/错误标记、持久outbox父标识、指标匿名/中介/无权限管理员拒绝及授权管理员可读，并保留全部业务回归。Collector跨主机接收、生产采样率/告警阈值与容量尚需环境验收，不能把本地SDK测试视为生产观测平台已部署。

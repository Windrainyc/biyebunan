# 公告与定向通知

管理员消息中心增加发送管理：公告/提醒、标题、纯文本正文、全部启用用户或指定启用用户（最多200人）。发布不可变，单次幂等创建并发送；本轮不增加定时发送/撤回/编辑已发送正文。全部范围包含三端当前启用账号，发布时数据库快照固定接收者。

持久化announcement及announcement_recipient，每个接收者独立event_id；同事务创建通知任务与outbox，由既有Rabbit消费者和数据库补偿处理，避免单消息大批量投递事务。管理员有独立发布/查询权限，普通用户只能通过接收者快照查看详情，不能获取发送对象列表。消息中心摘要200字内，详情最多10000字，纯文本显示防止HTML执行。收件箱已读状态用于发送统计。

验证指定/全部范围、未启用或无效接收者拒绝、越权详情404、发布幂等、Rabbit送达、重复消费、已读计数、真实接口及前端构建。新增迁移不修改历史迁移，使用隔离验证库。

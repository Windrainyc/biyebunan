# 用量目录与人工调账说明

## 学生模型目录

GET /api/v1/student/models仅展示启用的OPENAI_COMPATIBLE模型，必须有已生效启用价格、启用密钥，并通过网关部署开关和端点白名单检查。检查不发送网络请求，不能据此保证供应商在线或学生额度足够；创建运行时再次校验。

支持名称/代码字面搜索、三种白名单排序、分页。status=DISABLED返回空目录。部署配置过滤发生在分页之前，total与结果同范围；当前模型配置目录在内存过滤，适合管理型有限目录，模型数增长时需改为配置索引投影并保持总数一致，不能套用大数据集容量承诺。输出不包含供应商端点或密钥。

## 用量读取

学生GET /api/v1/student/usage只使用服务端身份；管理员GET /api/v1/admin/usage要求billing:read，可按studentId筛选，不包含提示词、回答正文或引用。q按运行UUID字面模糊查询，status为RESERVED/RECONCILING/SETTLED/RELEASED，from/to按UTC创建日期并包含首尾日期。分页与总数在同一数据库快照查询。

实际inputTokens/outputTokens/cachedTokens/amount在尚未确认时返回null，不能把未知显示成零。释放后的金额为0。priceVersionId指向固定价格。amount保留原始供应商结算金额，adjustmentAmount是人工净调整，netAmount是调整后费用，未知费用的netAmount仍为null。历史会员失效不隐藏已发生账务。

## 人工调整

POST /api/v1/admin/usage-adjustments要求billing:adjust及Idempotency-Key。输入为runId、DEBIT/CREDIT、正数人民币金额、原因和证据编号；证据由授权管理员核验，本接口不请求证据URL，也不把编号本身当作供应商自动证明。

仅允许对SETTLED运行追加调整。事务按额度账户→预占锁顺序，写入不可变billing_adjustment、ADJUSTMENT账本、更新账户spent_amount并写审计/outbox。重复HTTP键只返回原调整单。CREDIT不能超过该运行原始金额加累计调整净额。原始用量和结算不覆盖，词元统计不因金额退款改变。

本轮修订OpenAPI开发契约1.0.11：UsageEntry未知用量允许null并增加调整额/净费用；调整接口返回独立Adjustment，移除不适用的可更新ETag。原先返回UsageEntry无法区分原账单和调整单，故不机械复制。前端尚未开发，应按当前契约对接。

未知账务核对仍未完成。现有POST /admin/runs/{id}/reconcile的Reason→Job契约用于发起供应商核对，不能用此人工调整接口代替；RECONCILING保持冻结。后续需要可验证证据、查询适配器和明确不可查询状态。

## 本人资料

学生与中介各有GET/PUT /api/v1/{平台}/me。PUT只允许displayName、schoolId、majorId，要求If-Match和Idempotency-Key。按账户→院校→专业锁顺序校验匹配且启用；资料修改不变更authVersion，当前会话仍有效。禁止通过该入口修改角色、状态、密码、中介归属。教育字段沿用契约必填；若产品需要中介不填院校专业，后续统一修订契约和校验。

## 仍未完成

管理员证据核对、调整历史独立检索、私聊审计、论坛、字典前台查询、完整统计导出、PDF/Office/视频抽取和向量召回、真实扫描部署、对象GC、转码、受控死信重放、进行中订单取消补偿等。当前计费能力是部分实现，不代表全部后端已完成。

## 下一阶段核对实现约束

已检查operational_job当前是资产/索引任务的联合视图，核对任务不能写入该视图。应新增独立核对任务表并扩展视图，保持原任务状态和权限语义。核对结果包含供应商请求标识、输入/输出/缓存用量或明确无费用证明、证据摘要和时间；不允许从失败原因文本猜测实际费用。

RunCompletionService在取消或租约失效后不会接受迟到完成结果，当前会保持RECONCILING。后续需增加只追加的迟到用量证据入口，持有原owner/generation且绑定请求标识，不能直接重放原调用或覆盖流终态。核对结算按账户→运行→预占顺序，复用QuotaService.settle/release，保持失败/取消的对话终态和账务结算状态分别表达。

供应商查询能力须由适配器显式声明；通用OpenAI兼容Chat Completions不能假定都有按请求ID查询用量的接口。未配置查询能力时应明确返回不可核对状态并保留冻结，人工裁决需独立权限、证据与审计，不使用普通金额调整绕过。

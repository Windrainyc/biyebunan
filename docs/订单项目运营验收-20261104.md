# 订单、项目和运营改造验收（2026-11-04）

## 已实现与部署

云测试机 /opt/zhixiang 的 API、worker 和三端使用 orders-20261104 制品；数据库迁移 V61—V67 已应用。部署前备份位于 /opt/zhixiang/backups/orders-20261104/database.dump，未恢复或清空数据库。保持原 HTTPS IP 入口、现有数据与消息隔离，网关已校验并平滑 reload。

- 订单号服务端生成 ZX + 上海时间 yyyyMMddHHmmss + 10位随机十六进制大写字符，唯一索引保护；默认 CNY。
- 服务套餐独立维护、启停、分页搜索与下拉；中介只能读取启用套餐。历史套餐代码回填，未任意修改旧订单。
- 状态迁移原因可选；收款凭证、支付流水、渠道、金额、时间、备注均可选。填写时仍校验类型、金额和凭证 READY 状态，缺金额不会虚构实际收入。
- 订单删除支持无绑定、无收款、无项目引用的 DRAFT/CANCELLED；保留 CAS、幂等、审计及引用保护，不级联删除账务。
- 项目支持最多20个扫描通过的需求素材；授权下载、引用删除保护。前端选订单带入可修改标题、默认七天后交付。
- 里程碑入口和阶段推进门槛移除，历史记录保留。项目进度按阶段映射，验收仍要求应有发布资料及订单状态。
- 六类交付按批次事务发布，每类本次一个文件，未更新类别保留；旧版本不可变，幂等重放不重复发布，批次通知不重复。
- 登录、页面、知识学习与业务审计提供真实用户活动分页、日期/用户/类型筛选和每日汇总。服务器识别身份、时间和客户端 IP，不采集URL查询参数或答疑正文；时长仅累计可见、聚焦且近期有操作的页面片段，并限流、去重、限制每账号时间桶。属于活跃时长估计，不能证明专注学习。
- 管理端数据统计使用 ECharts 真实图表；没有数据时不虚构指标。

使用 org.lionsoul:ip2region:3.3.7 和固定数据提交 6a276cc7c4f9f2d7ff1d8ace14b91af59752f943。
IPv4库 SHA256：46249ad1b33bcaa4cc37475b93746cec2b00acffc3316cc4f56167ac821ea2ad。
通过 scripts/download-ip-region.py 下载校验；数据库不入Git，云端只读挂载 /app/ip-region，ZX_IP_REGION_V4 指向该目录的 ip2region_v4.xdb。授权文本见 third-party/ip2region-LICENSE.md。
当前只部署IPv4库，IPv6/无记录明确显示未知；地点是出口IP近似归属地，代理网络会显示代理出口，非GPS。Spring仅信任回环/部署Docker网段转发头，公网网关覆盖而非透传客户端X-Forwarded-For，API未直接公网暴露。

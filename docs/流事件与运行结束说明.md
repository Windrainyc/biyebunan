# 持久流、消息与运行结束（阶段交付）

## 已实现与未接通边界

V29保存generation_run、run_event，V30保存不可变chat_message。已提供学生SSE事件订阅和消息历史查询。运行领取、调用起点及结束事务是内部用例，测试直接在隔离数据库准备运行数据。

**尚未开放创建生成任务的完整业务入口。** 模型选择、上下文及引用快照、创建运行与预占的事务、调用执行器、取消及管理端核对仍需接通。不能把读接口和内部结束服务视为学生已经可以提交问题并得到真实模型回复。默认不调用付费模型。

## 运行与账务一致性

- 学生与会话通过复合外键固定；模型与价格通过复合外键一致。学生范围client_message_id永久唯一，尚待创建用例实现同键参数摘要比对。
- 只有存在RESERVED额度预占的运行可领取。准备租约30秒，领取使用FOR UPDATE SKIP LOCKED，代次递增；旧领取者无法标记调用开始。
- 开始调用必须先以单独短事务写入RUNNING和调用起点，租约延长至4分钟。外部HTTP只能在该事务提交之后发生。已开始的运行不再进入领取队列，即使租约到期也不能盲重试。
- RunCompletionService锁顺序为额度账户→运行→预占。成功时实际用量结算、最终消息、usage事件、completed事件和运行SUCCEEDED同事务；异常则全部回滚。空答复但存在实际用量时记录费用并以MODEL_EMPTY_RESPONSE失败，不伪造文本。
- 重复完成的实际用量与正文必须完全一致，不能重复结算或覆盖消息；旧代次结果拒绝。
- 明确无费用拒绝释放预占；断流等未知结果保存FAILED+RECONCILING及failed事件，冻结不丢失。当前缺少授权人工核对入口和过期调用自动核对调度，不能声称已完成恢复闭环。

## 流协议与恢复

`GET /api/v1/student/runs/{id}/events`返回text/event-stream。id为runId:sequence，event取accepted/delta/citation/usage/completed/failed/cancelled，data为契约StreamEvent对象。服务器从Last-Event-ID之后读取，回放绝不调用模型或变动账务。

序号分配和事件插入同事务，运行行锁保证多节点顺序。事件不可UPDATE，accepted与终态事件有唯一约束，终态之后拒绝追加。每条payload限制64KiB。默认回放期限7天；如果要求回放的连续事件已丢失或过期，首次请求返回410；游标跨运行、负数、溢出或超前返回400。

每连接最多30秒，15秒注释心跳，客户端须用最后收到的ID重新连接。终态且已读完则立即关闭。每进程最多64连接，超过返回429；4个调度线程每秒读取至多100个事件。这些是当前有界保护参数，**不是经过负载测试的并发容量承诺**。数据库/应用多副本仍需连接池和负载压测后调优。

每批事件前重查会话撤销、认证版本、学生状态、权限、会话隐藏及订单归属。运行中权限失效时关闭流，重连重新鉴权；这不是零延迟撤权保证。异步Servlet完成分派重新认证，未放宽HTTP安全规则。配置Cache-Control:no-store、X-Accel-Buffering:no；生产代理还应配置合理读超时。

## 消息历史

`GET /api/v1/student/conversations/{id}/messages`支持分页、正文关键字及白名单排序，其他学生404、中介403。无启停字段，因此移除原契约通用status过滤。消息不可覆盖或删除，同运行同角色唯一。用户正文上限16000字符，助手上限262144字符，超过明确失败，不截断。消息updatedAt排序按不可变消息createdAt处理。

当前消息保存的是未接入RAG的文本，citations为空数组；不会伪造引用。来源快照与当前权限复查接入之前，不得向此接口塞入未经来源权限过滤的引用文本。

# 本地可靠性验证

## 备份恢复

执行 `python3 scripts/verify-backup-restore.py`：只读备份本地app schema，创建随机zx_restore_隔离数据库，安装同版本vector扩展、恢复全部表数据及约束，对照源库所有表行数并确认约束有效，结束后删除本次创建的数据库。临时备份权限0600、目录0700，不上传、不提交。

本次86张物理表核对通过，过程7.34秒，备份约299KB。数据量很小，不构成生产RPO/RTO承诺。对象存储版本、跨机复制、异地备份、密钥托管及真实灾难恢复尚未验收。正式备份需要数据库和对象清单联合策略，不能只备数据库。

## 同机双API验证

两个独立Spring容器共享隔离schema，通过真实HTTP验证同幂等键并发写只创建一次、身份撤销同步生效、关闭一个实例后另一实例仍健康。进一步以8并发发送64个鉴权分页读取请求，均返回200；本次P50 7ms、P95 13ms，批次68ms。仅本机小样本组件验证，不是生产吞吐、持续高负载或跨主机故障转移证明。每次复跑数值可能不同，机器可读结果以local-load-verification.json为准。

跨节点生产编排仍遵循既有架构设计，应用、worker、中间件分别部署；真实集群未部署，不将Compose或同机双实例宣称高可用。

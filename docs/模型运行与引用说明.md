# 模型运行与引用说明

## 已实现的纵向流程

学生POST `/api/v1/student/runs`提交会话、clientMessageId、正文、模型、知识版本与输出上限。服务端验证当前身份、会话及订单归属，选择已启用模型、已生效价格和密钥；固定请求上下文后，在同一事务创建运行、额度预占、用户消息、accepted和citation事件。Idempotency-Key处理HTTP重放，clientMessageId在学生范围唯一且比对请求摘要，换HTTP键不会重复预占。

独立worker领取RESERVED任务，准备上下文及密钥后提交调用起点，再在事务外请求供应商。增量分段短事务持久化；成功时实际用量、追加账本、回答和终态同事务提交。运行领取有代次fencing；已记录调用起点的任务绝不重新派发，不能宣称供应商exactly-once。

GET运行、消息历史与SSE均验证当前访问范围。SSE仍使用持久序号和Last-Event-ID回放，不重新调用或收费。

## 取消、失联与账务

取消是单调意图，支持幂等键，契约不要求If-Match。尚未发起调用时释放预占；RUNNING取消进入未知用量核对，阻止后续增量写入，不承诺供应商已停止或免费。运行租约过期后，恢复线程按账户→运行顺序重新加锁、复查，冻结预占并写未知结果终态，不自动重试付费调用。管理员证据对账和账务调整接口仍待实现。

V32将quota_hold的运行与价格复合外键指向generation_run，并禁止修改运行归属、clientMessageId、请求摘要和价格身份。升级遇到旧孤立预占应停止并人工核查，不自动清空历史财务记录。

## 上下文与知识来源

当前支持最多8个不同的已发布、索引就绪Markdown知识版本，每版本取前4个授权分片；这是显式引用，不是向量相关性召回。引用正文作为用户数据，系统提示要求忽略其中的执行指令。chunkId与引用快照不可变；page目前表示Markdown分片序号，不代表PDF页码。

上下文包括固定系统提示、来源、最近最多20条无引用成功历史和当前问题。输入按UTF-8字节数加消息开销保守估计，超预算逐条丢弃最旧历史，当前问题或引用仍过大则拒绝。该估算不是供应商精确tokenizer；实际结算使用供应商返回用量。带引用历史暂不传入后续上下文，避免撤权后的间接泄露。

执行前、每次增量、SSE每批及历史查询复查来源权限。来源撤回后运行查询和SSE拒绝，历史回答隐藏。权限变更与已经发出的外部请求无法跨系统原子协调，不承诺即时撤回供应商已接收的数据。

## 配置与边界

模型网关默认关闭。生产仅允许HTTPS和显式主机白名单；密钥加密保存，运行仅存密钥ID，执行时解密。测试专用本地HTTP服务仅存在于src/test，使用隔离凭证与确定性输出，不用于生产。

worker调度线程池为6；运行领取及恢复使用数据库协调。节点数和连接池需按数据库连接预算配置，目前未进行多节点故障、容量或负载测试。准备阶段基础设施失败可在租约过期后重领；调用阶段基础设施失败只能进入未知核对。

仍缺学生可用模型目录、完整用量查询、管理员核对证据与调整、PDF/Office/视频抽取、向量召回、真实扫描部署、对象GC、论坛、统计导出、受控死信重放及进行中订单取消补偿。未实施生产部署或真实付费调用。

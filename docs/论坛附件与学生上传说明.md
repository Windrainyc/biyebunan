# 论坛附件与学生上传

## 权限与生命周期

学生先以空附件列表创建帖子，再通过学生上传接口申请 FORUM 签名，ownerId 必须是本人处于 PENDING/PUBLISHED 且板块启用的帖子。学生不能通过改变 ownerType 写入项目交付、知识库或收款证明。管理员写论坛文件还须具备帖子审核权限。

文件仍走真实 S3/MinIO 直传、摘要与长度校验、扫描隔离、不可变私有副本流程。只有 READY、未删除且归属同一帖子的文件能通过 PUT 帖子关联，最多20个、不允许重复。审核发布再次复核附件状态。新建帖时不能引用其他帖子的附件，失败事务整体回滚。

作者可查看自己未关联的文件状态和 READY 文件预览；其他学生只可下载已发布/锁定、板块启用、仍被帖子引用的附件。帖子隐藏、删除、板块停用、撤下引用后拒绝新的授权。已经签发的URL最多仍在原一分钟有效期内可用，这是对象存储签名的明确边界。管理员查看附件仍要求对应帖子读取权限。中介没有论坛私有文件权限。

## 并发与数据库

V41增加forum_post_id归属外键、恰好一个归属列的CHECK约束和forum_post_asset关联。写入顺序为账户幂等锁→板块→帖子→按ID排序的资产；帖子编辑的标签树锁在板块之前。上传完成和删除资产也先锁所属帖子，避免关联与删除互相越过。已被正文引用的资产删除返回409，不能产生悬空引用。

## 验证边界

真实MinIO签名PUT和GET验证内容一致；真实PostgreSQL隔离schema验证归属、扫描前拒绝关联、隐藏撤权和删除保护。测试扫描器使用确定性替身，不代表已部署病毒引擎；实际环境未配置扫描服务时仍保持隔离。没有调用付费模型或外部短信。

# 通知模板渲染

交付发布使用固定业务代码DELIVERY_PUBLISHED选择IN_APP模板。providerTemplateId为服务端注册的渲染器代码，当前支持delivery-published-v1和delivery-published-brief-v1，不执行数据库中的脚本或表达式，不在通知中嵌入学生私聊、源代码、签名链接或项目敏感原文。

未配置该业务模板时使用内置正式默认通知；显式DISABLED或渲染器不受支持时，业务交付仍成功，通知任务记录FAILED及TEMPLATE_DISABLED/TEMPLATE_RENDERER_UNAVAILABLE，不伪造投递。管理页可配置目录，短信模板仍只管理供应商编号，不自动发送真实短信。

领域事务中固定模板ID、版本、渲染代码和安全文案。后续模板更新不会改写已排队通知，相同事件重放复用原快照。模板有历史任务引用时通过RESTRICT外键保护不能删除；可停用。worker继续以SKIP LOCKED和收件箱唯一约束原子投递。

真实PostgreSQL测试覆盖版本快照、配置更新后文案不变、禁用/未知模板不发送、引用删除保护。通知长期保留和正文匿名化策略尚未启用，需后续提供有界保留任务及可配置默认值，不能把本轮渲染能力当作保留期能力已完成。

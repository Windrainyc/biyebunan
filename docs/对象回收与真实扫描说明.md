# 对象回收与真实扫描

## 回收范围

V47新增asset_object_gc。worker只处理持久记录中的完整对象键，不接受客户端前缀。上传签名到期超过一天后，回收未完成、READY或REJECTED资产的隔离源；QUARANTINED保持源对象等待扫描。私有对象须软删除超过七天且无业务引用。数据库历史记录保留。

扫描复制前先登记新的随机私有键和验证代次，外部复制在事务外执行；进程在复制后落库前崩溃，仍能定位孤立对象。有效验证租约保护对应副本；已成为当前私有对象的键不回收。业务已引用的现用副本也不回收。退休规则不能恢复为可写，过期上传会话不能再次完成。

回收使用五分钟租约与generation，失败十分钟后重试；成功后每日复查相同精确键，以处理旧进程长暂停后的迟到写入。每批最多删除一千个版本，包括版本化存储的历史版本；只匹配完整键，类似前缀对象保留。对多版本超过上限返回继续状态。外部删除失败不标记成功。删除后业务无需恢复，因此过期执行器重复删除同一退休键是幂等动作。

## 真实扫描

本地中间件compose.scanner.yaml部署官方ClamAV 1.4.6 LTS与持久病毒库，镜像摘要固定。当前ARM机器以amd64兼容方式运行，已实际启动healthy。官方freshclam完成病毒库下载与校验；普通测试文本返回OK，内存EICAR无害测试串返回FOUND，Java真实适配器集成测试也通过。并发扫描线程为2，容器内存上限4GiB，超限告警不放行。配置地址ZX_CLAMAV_HOST/ZX_CLAMAV_PORT已写入受保护本地环境文件，不打印凭证。

宿主机127.0.0.1:13310；容器网络使用clamav:3310。真实扫描测试以环境是否配置决定运行；本轮实际执行，没有跳过。生产扫描资源和视频大文件耗时仍需容量测试，当前120秒请求截止时间不代表任意2GiB文件都能在该时间内完成，超时保持隔离。

参考：[官方Docker部署说明](https://docs.clamav.net/manual/Installing/Docker.html)、[官方版本下载](https://www.clamav.net/downloads)。

# PDF与Office文档抽取

本地独立Tika 4.1.0容器已启动，镜像固定摘要见本地环境compose.scanner.yaml。配置ZX_TIKA_ENDPOINT；未配置时任务明确失败，不伪造索引成功。

知识索引只读取已扫描通过、未删除的资产私有对象及固定对象版本，经独立解析服务提取文本，然后走原有分片、发布代次屏障和权限过滤。输入上限50MiB，输出上限2MiB及500000字符，调用100秒超时，不自动重试HTTP，不跟随重定向。无文本扫描版PDF明确返回DOCUMENT_TEXT_EMPTY；未实现OCR。

真实Tika验证内存生成PDF和DOCX文本，完整集成套件另验证缺失对象失败，不把测试替身当成真实文件。64项测试通过，未产生云端或模型费用。视频转写与向量召回仍未实现；VIDEO任务仍明确失败。生产需要部署隔离解析服务并评估容量，本地通过不代表生产压测。

# 知识库与任务运行说明

管理员通过knowledge接口创建草稿、编辑、submit-review、publish、withdraw。所有业务写要求Idempotency-Key，更新/状态迁移/任务重试/索引重建要求If-Match。已发布内容不可直接编辑，须先撤回；学生不会读到草稿。

视频/文档先创建assetId为空的草稿，再以ownerType=KNOWLEDGE、ownerId=内容ID申请上传。扫描READY后将资产ID写回草稿。Markdown正文最大20万字符，不混用附件。分类必须启用、标签最多20且不能重复。历史内容和快照引用会阻止删除分类、标签或资产。

worker启动后处理Markdown发布索引，ZX_INDEX_POLL_MS默认1000毫秒。当前关键词检索返回原文引用；没有付费embedding调用或伪造向量。PDF/Office/视频正文抽取尚未实现，任务明确FAILED，errorCode为CONTENT_EXTRACTION_UNAVAILABLE。修复抽取能力后可通过内容reindex恢复。

任务详情、列表、资产任务retry已接入。资产校验任务只允许对FAILED且仍隔离的资产恢复，恶意文件拒绝不允许通过重试绕过。知识索引用内容重建接口恢复；其他未来任务类型尚未伪装实现。

worker声明独立持久队列zx.activity、死信交换机zx.activity.dead.exchange和zx.activity.dead队列，订阅既有事件交换机。该消费只维护事件日计数，使用inbox_event的activity-v1消费者键。数据库失败或协议不符进入死信队列，当前尚无Web重放操作；不得直接清空死信队列。zx.tasks仍保留给后续业务消费者。

当前未完成：真实扫描服务/病毒库、对象GC、文档/视频抽取与转码、向量召回、付费模型适配及持久SSE、额度账本/对账、论坛/统计展示和导出。事件日计数表存在不等于统计API完整。

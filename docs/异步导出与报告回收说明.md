# 异步导出与报告回收

## 业务与权限

管理员可申请ORDERS/PROJECTS/USAGE/AUDIT，中介仅ORDERS/PROJECTS；除导出权限，还必须拥有相应业务查询权限（USAGE为billing:read）。日期为北京时间自然日、首尾包含、最多366天。ORDERS按订单创建，PROJECTS按项目创建，USAGE按预占创建时间并显示当前账务状态，AUDIT按事件创建。报告字段固定白名单，不包含手机号、凭证URL、密钥、聊天正文或任意detail JSON。审计私聊元数据只有chat:audit可导出，并在下载时再次要求此权限。

每人最多3个排队/执行任务、每小时20次申请，入口账户锁与幂等记录防止并发绕过；相同幂等请求返回原任务。最多10000行、20MiB，超出明确失败，不能静默截断。CSV使用UTF-8 BOM、正确引用引号换行，并中和公式前缀。

生成时重验账户启用、平台和业务权限。下载仅允许原申请者，重验相同权限；中介报告保存所有订单ID，任一归属变化就拒绝整份报告。已签发链接最长60秒仍可能有效，无法假装即时撤销对象存储签名。报告成功后24小时有效，下载行为留审计。

## 事务、租约和清理

V44持久export_job、export_order_scope、export_attempt。独立worker使用SKIP LOCKED领取，租约5分钟、generation fencing、最多3次租约恢复；每次尝试使用全新对象键。读取报告数据和保存范围在同一重复读事务，锁任务防止旧代次覆盖新范围；S3写入在事务外，If-None-Match禁止覆盖。完成时再次复核权限和范围且只有有效代次可设置成功。已生成文件与用户上传资产分离，因此Job.resultAssetId为空，下载通过job端点完成。

每次尝试在网络写入前登记对象键。失败/失效尝试超过1小时、或者成功报告过期后可清理；缓冲超过对象客户端120秒硬超时。回收仅删除登记键/版本，不扫描删除桶，404视为幂等完成。未知版本先HEAD定位，再删对应版本。清理失败保留记录等待回收租约再次到期；已清理记录每天复核一次，以回收进程异常长暂停后极迟到的写入，不能仅凭网络超时宣称不会有迟到对象；租约恢复不会覆盖已有私有报告。

导出存储由ZX_EXPORT_STORAGE_ID指定，未指定回退ZX_UPLOAD_STORAGE_ID；必须启用私有配置。存储配置一旦被报告引用不能改变位置，外键保护删除。后台任务列表合并EXPORT_类型，失败任务需重新申请而非沿用旧范围强制重试。

## 验证范围

真实MinIO验证对象写入、下载字节、报告过期删除；真实数据库测试中介归属转移、业务权限撤销、排队后撤权、租约过期恢复、失效尝试清理、不同申请者访问拒绝、幂等任务创建。覆盖四种报告查询及CSV公式/引号/换行边界。并未验证真实多节点集群或生产负载。

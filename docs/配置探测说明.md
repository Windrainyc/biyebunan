# 配置探测

模型、存储和域名的 `/test` 接口接受必填 reason 与 Idempotency-Key，创建持久任务返回202。任务查询复用管理员jobs接口。任务记录申请时配置版本，不直接更改配置启停状态。

独立worker通过PostgreSQL SKIP LOCKED领取；租约一分钟，代次递增，最多领取三次。外部请求在数据库事务外执行。执行前和结果写回前重新核对账户、权限及配置版本，凭证变化也拒绝旧结果。过期执行器不能覆盖当前代次。重试需重新申请以绑定最新配置。单人最多三项排队/运行任务、每小时二十项申请。

## 能力边界

- 存储：使用真实S3/MinIO凭证检查桶存在和读取权限，不创建测试文件，不证明写权限。
- 模型：只对兼容的chat/completions端点派生GET models，校验目录包含配置模型代码；不发送推理请求，不验证生成质量或模型计费。供应商不支持目录协议时明确失败。
- 域名：检查DNS、系统信任链TLS证书及HTTPS HEAD响应；不自动申请证书、部署域名或验证完整应用业务。HTTP 5xx判失败，其他状态表示可建立响应，不能解释为业务正常。

模型和域名网络探测默认关闭。部署配置ZX_CONFIG_PROBES_ENABLED=true，并以ZX_PROBE_ALLOWED_HOSTS配置精确主机白名单。生产仅HTTPS，禁止重定向，拒绝私网/回环/链路本地/多播/IPv6 ULA/共享运营商地址；固定DNS结果避免连接时二次解析。DNS解析最多等待五秒、最多两个并发解析线程，HTTP调用最多二十秒。模型响应上限1MiB。测试构造器可允许隔离本机HTTP，不提供生产环境绕过开关。秘密不写任务、错误、审计或日志。

错误码保留具体失败类型：PROBE_CONFIG_CHANGED、PROBE_PERMISSION_REVOKED、PROBE_ATTEMPTS_EXHAUSTED、CONFIG_PROBES_DISABLED、PROBE_TARGET_DENIED、MODEL_CREDENTIAL_REJECTED、MODEL_NOT_LISTED等。任务成功是某一配置版本的历史检查结果，不是永久健康承诺。

## 验证边界

使用真实MinIO和隔离PostgreSQL schema验证存储探测、幂等、权限撤销、配置变化、租约代次；模型使用隔离HTTP服务验证目录、鉴权失败、大响应和重定向拒绝，不连接真实供应商。公网DNS/TLS成功路径需在部署白名单配置后验证，未声称已验证真实生产域名。
